Countries Dashboard API

This API lets you configure and retrieve dynamic dashboards for countries, with weather, currency, and population data.

Endpoints

  • /dashboard/v1/registrations/{?id} – Create and manage dashboard configurations
  • /dashboard/v1/dashboards/{id} – Fetch a populated dashboard by ID
  • /dashboard/v1/notifications/{?id} – Register and manage webhooks for events
  • /dashboard/v1/status/ – Check API availability and uptime

Example Request – POST

Create a dashboard config

{
  "country": "Norway",
  "isoCode": "NO",
  "features": {
    "temperature": true,
    "capital": true,
    "targetCurrencies": ["USD", "EUR"]
  }
}

Example Request – PUT

Update entire config by ID

{
  "country": "Sweden",
  "isoCode": "SE",
  "features": {
    "temperature": false,
    "area": true,
    "targetCurrencies": ["EUR"]
  }
}
